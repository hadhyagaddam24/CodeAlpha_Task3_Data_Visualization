CodeAlpha Task 3 - Data Visualization

Project Title

Sales Data Analysis and Visualization

Objective

The objective of this project is to analyze sales data using Python and create meaningful visualizations to identify trends, patterns, and business insights.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Visualizations

1. Monthly Sales Trend
2. Sales by Product Category
3. Sales Distribution by Category
4. Sales by Region
5. Profit by Product Category
6. Sales vs Profit
7. Sales by Sub-Category
8. Correlation Heatmap

Key Insights

The analysis provides insights into monthly sales trends, category performance, regional sales, profitability, sub-category performance, and relationships between sales, profit, quantity, and discount.

Conclusion

This project demonstrates how Python-based data visualization can transform raw sales data into meaningful insights and support data-driven decision-making.
